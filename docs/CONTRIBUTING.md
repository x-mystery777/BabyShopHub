# Contributing to BabyShopHub

## Workflow

1. Start from the latest `develop` branch.
2. Create a focused `feature/<short-name>` branch.
3. Make small, meaningful commits.
4. Run the relevant tests and checks.
5. Open a pull request into `develop`.
6. Address review comments before merge.

## Pull request checklist

- [ ] Linked GitHub issue
- [ ] Scope is limited to the assigned task
- [ ] Tests or test evidence included
- [ ] Documentation updated when an interface changes
- [ ] No secrets or generated local files committed
- [ ] Another team member reviewed the change

## Integration rule

Feature teams must document API or database changes before merging code that depends on them. The Project/System Lead coordinates cross-team integration and resolves conflicts.
